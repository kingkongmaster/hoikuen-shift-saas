# ブランド名称・ロゴ予備調査報告書

## 文書情報

- 調査日：2026年8月5日
- 調査目的：園シフトの試供版で使用する名称・ロゴについて、正式公開前に追加確認が必要な事項を整理する
- 対象：園シフト、EnShift、エンシフト、AeN_Shift、AeN Shift、AeN、ネットフォースマスター
- 調査の位置付け：公開情報を用いた予備調査であり、商標の使用可否・登録可能性や著作権非侵害を保証する法的鑑定ではない

来週のむすび保育園プレゼンでは、現在の名称とロゴを**開発中の仮名称・仮デザイン**として使用する。正式公開や商品化の前に、商標専門家による確認を行う。

## 使用した公開データベース等

- J-PlatPat（日本の特許・商標情報検索）
- USPTO Trademark Search（米国商標検索）
- WIPO Global Brand Database（国際・各国商標情報の横断検索）
- EUIPO Search IP／TMview（EUおよび参加官庁の商標検索）
- 公開Web検索

文字の完全一致だけでなく、大文字・小文字、空白、アンダースコア、読み方、類似する綴りも確認対象とした。ただし、指定商品・役務、称呼、観念、図形の総合的な法的判断は行っていない。

### Enshiftという同名使用

公開Web上で、`Enshift`を名乗るベルギーのIT事業者を確認した。同社はクラウド、業務自動化、Webアプリ、モバイルアプリ等を扱っており、本サービスと技術分野が近い可能性がある。商標登録の有無とは別に、商号・未登録使用・市場での混同可能性を専門家が確認する必要がある。

### WIPO・EUIPO／TMviewの未確認範囲

WIPO Global Brand DatabaseとEUIPO／TMviewの動的検索画面は、調査環境から検索結果を安定して取得できなかった。このため、国際登録、EU商標、参加各国の登録について網羅的な結果確認は完了していない。検索日時、検索式、指定商品・役務を記録できる環境で再調査する。

## ロゴの予備調査

現行ロゴは、**カレンダーの図形に2枚の葉を組み合わせたデザイン**である。リポジトリには32px、180px、192px、512pxのPNGアイコンと、1170×2532pxのスプラッシュ画像がある。SVG、AI、PSD、EPS等の編集可能な元データや生成経緯を示す資料は確認できていない。

### ウィーン図形分類の検索候補

- `20.5.3`：カレンダー
- `5.3.11`：その他の葉
- `5.3.13`：図案化した葉
- `5.3.15`：2～4枚の葉

文字商標検索とは別に、上記分類の組合せ、カレンダー単体、葉単体、カレンダー＋葉の複合図形、画像類似検索を行う必要がある。今回、WIPO・TMview等による画像類似検索は完了していない。

名称・図形の追加調査と、文字の読みやすさ・色覚多様性・コントラスト確認が完了するまで、若葉色への変更は保留する。

## 調査限界と次の対応

- 簡易検索には検索対象・検索式・更新時点による限界がある。
- 登録商標だけでなく、出願中、失効、未登録使用、商号、ドメイン名、アプリ名も追加確認が必要である。
- 商品・サービスの区分が異なっても、内容が関連していれば混同のおそれが残る。
- 文字の一致だけでなく、称呼、意味、外観、ロゴ全体の印象を確認する必要がある。
- 調査対象国・地域を事業計画に合わせて確定する必要がある。
- 正式公開、出願、色変更の前に、商標を扱う弁理士等へ検索結果と現行ロゴを渡して確認する。

本報告書から「世界的に問題なし」「商標登録可能」「著作権侵害ではない」「同一名称や同一図形が存在しない」「専門家確認が不要」とは結論しない。
