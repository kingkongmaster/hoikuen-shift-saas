# AeN Shift Development Principles

- **共通化優先**  
  園固有の処理を増やす前に、全テナントや他のアプリでも使える共通構造を検討します。

- **再利用優先**  
  既存の部品、API、検証手順、文書を再利用し、同じ仕組みを重複して作りません。

- **過去知見の活用**  
  作業前にNotion「アプリ開発ログ」とGitHub履歴を確認し、過去の判断・失敗・回避策を活用します。

- **最小実装**  
  目的に必要な最小差分を選び、無関係な機能・DB・設定へ変更を広げません。

- **最小記録で最大価値**  
  作業量ではなく、目的・原因・検証・再発防止・関連Commit／PRを短く残します。

- **人にもLLMにも理解しやすい構造**  
  曖昧な「対応済み」を避け、見出し、具体的な対象、結果、参照先を一貫した形式で記録します。
